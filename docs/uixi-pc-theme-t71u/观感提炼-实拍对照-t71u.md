## 0. 取样说明（先读）

- 正片 PNG 文件尺寸多为 **1280×800**，画面含浏览器铬（标签、地址栏 `127.0.0.1:18202`）。部分帧有 Google 翻译气泡，**不是产品 UI**。

- 侧栏右缘图上约 149px，按同一比例换算约 **224 CSS px**，与锁宽一致。
- **颜色不随缩放改变。** 主按钮实心取样是颜色结论的依据。
- 只读旁证（未改源码）：`apps/web-antd/src/preferences.ts` 把主色写成与 Ant Design 默认蓝同一套 HSL，并把 `VITE_APP_TITLE` 定为 `Plus Admin`。旁证只用来解释观感，**不覆盖 UQ 锁色**。

## 3. 壳层（实拍句子）

登录后壳层从外到内是：

1. 顶栏白底固定：左面包屑（如「系统管理 / 用户管理」），右租户选择、搜索、主题、语言、全屏、通知、头像。
2. 其下 chrome 标签，可关。分析页、工作台、各管理页会叠标签。
3. 左侧白栏约 224px。分组：概览、系统管理、租户管理、系统监控、系统工具、测试菜单、PLUS官网、工作流、我的任务、关于。当前项浅蓝块。
4. 栏头字标是 **Plus Admin**，不是园擎。
5. 内容区底 `#F1F3F6`，业务块是白卡片。
6. 应用内无页脚。登录页（辅帧，不在 52 正片）底仍有 Vben 版权。

这与 UQ §2、梯控 §5 的浅色壳层同一结构。要改的是字标和主色观感，不是侧栏深浅。

## 4. 右抽屉与居中 Modal

### 4.1 实拍在用的规则

| 场景 | 实拍容器 | 证据 |
| --- | --- | --- |
| 字段较多的增改，或带菜单权限树 | **右抽屉** | 用户、角色、菜单、部门、岗位、客户端、租户、租户套餐、OSS 配置、SpEL、请假 |
| 短表单（大约几个字段、无树） | **居中 Modal** | 字典类型、参数设置、流程分类 |
| 从库里挑数据、或上传文件 | **居中 Modal** | 代码生成「导入表」、文件上传 |
| 富文本公告 | **宽居中 Modal**（只读 `w-[800px]`），不是抽屉 | 通知公告 |
| 上传本身即完成 | **居中 Modal 且无页脚** | 文件上传：只读 `:footer="false"`，关窗时若已有文件再刷新列表 |
| 业务需要暂存 | 右抽屉，页脚三钮 | 请假：「取消 / 暂存 / 确认」 |

标准页脚（用户、角色、菜单、部门、岗位、参数、字典、公告、流程分类、流程定义、SpEL、OSS 配置）：**取消（浅）+ 确认（主色）**，右对齐，顶部分割线。

流程定义「新增」**画面是居中弹窗**。只读文件 `process-definition-modal.vue` 使用 `useVbenModal`，宽度类 `w-[550px]`，返回值被命名为 `BasicDrawer`。以实拍为准：它是 Modal，不是右抽屉。

### 4.2 和两份基线的差别

- 梯控 / UQ：「几乎一律右抽屉；Modal 约 400，主要用于审批。」
- 本批平台实拍：抽屉与居中 Modal **并存**。Modal 用于短表单、挑选、上传、富文本，宽度默认约 520（`w-130`）、显式 550 或 800，**不是一律 400**。
- 本批**没有**拍到审批 Modal。400px 审批档保留为梯控遗产，是否仍为园区审批专用，**待林裁定**。
- 抽屉主档实拍旁证是 **600 / 650 / 800**，不是梯控电梯域的 **550 / 650 / 800**。修订稿两套档都写明适用面，不把 550 从电梯域记忆里删掉。

### 4.3 宽度（图宽仅作比例校验）

| 只读 class | 代表 | 图上白面板宽（1280 成片） | 按 2/3 回推 |
| --- | --- | --- | --- |
| `w-[600px]` | 用户、菜单、部门、岗位、客户端、租户（骨架）、请假、SpEL | 约 399 | 约 600 |
| `w-[650px]` | OSS 配置编辑 | 约 433 | 约 650 |
| `w-[800px]` | 角色、租户套餐 | 约 533 | 约 800 |
| 默认 `w-130`（约 520px） | 流程分类（另有 `min-h-[500px]`）、字典类型、文件上传未写宽 | 流程分类图宽约 346 | 约 519 |
| `w-[550px]` | 参数设置；流程定义新增（居中） | 未逐帧量壳宽；形态为居中 | 550 是 class，不是另一套「看起来像 400」的抽屉 |
| `w-[800px]` Modal | 通知公告、导入表 | 居中且明显宽于短表单弹窗 | 800 |

## 5. 列表、工具栏、分页、主从

### 5.1 列表骨架（一致的部分）

1. 查询：若干字段 + **重置** + **搜索（主色）** + **收起**。
2. 表标题在左，工具在右。
3. 表格：勾选列（树表为展开箭头）、数据列、操作列。
4. 分页在卡片底：左计数与每页条数，右页码。字典左右各一套分页。
5. 无数据：插画 +「暂无数据」（租户套餐、请假、流程定义已发布列表）。

### 5.2 主从（UQ 原先没写，本批要补）

| 页面 | 实拍结构 | 增改容器 |
| --- | --- | --- |
| 字典 `/system/dict` | **左「字典类型」表 + 右「字典数据」表**。各自查询、工具栏、分页。点类型，右侧出数据 | 类型「新增」= 居中 Modal（名称 / 类型 / 备注）。数据行的增改抽屉**本批没单独拍**（只读存在 `dict-data-drawer.vue`，`w-[600px]`） |
| 用户 `/system/user` | 左部门树 + 右用户表 | 新增 = 右抽屉 |
| 流程定义 | 左分类树 + 右表（已发布 / 未发布） | 新增 = 居中 Modal |
| 部门、菜单 | **单表树**（收起/展开），不是左右分栏 | 新增 = 右抽屉 |

梯控的「左区域树 + 右表」与用户页、流程定义同类。字典双表是平台多出来的主从，修订稿单独写。
