### 1.3 现网观感备注（t71u · 不改上表 HEX）

取样环境：`127.0.0.1:18202` Plus Admin，浅色，中文。主按钮实心像素 **`#1476FE`**。

| 角色 | 锁色（上表） | 18202 观感 | 处理 |
| --- | --- | --- | --- |
| 主色 | `#006BE6` | ≈ `#1476FF`，色差离 Ant `#1677FF` 约 2，离锁色约 33 | **待林裁定**。裁定前效果图与 Figma 仍用 `#006BE6` |
| 成功 | `#57D188` | 列表「正常 / 启用」走主色浅标签或主色开关，不是这块绿。零星绿点近 `#50C418` | 锁色不改。状态标签的主色浅底写进 §3，不新造成功色 |
| 警告 | `#EFBD48` | OSS 配置抽屉黄条，观感偏 Ant 警告金 | 锁色不改 |
| 危险 | `#FF3860` / 底稿 `#FF4D4F` | 「删除」红字链。未用 DevTools 读 `--destructive` | 锁色不改，仍「以运行实测为准」 |
| 圆角 | 8px | 只读偏好 `radius: '0.375'`（约 6px，注释写明对齐 antd）。缩放图不足以单独改锁 | **仍锁 8px**，待林裁定 |
| 侧栏 | 浅色白 `#FFFFFF` | 白底，选中约 `#DCEBFF` | **与锁一致**，不是深色侧栏 |
| 内容底 | `#F1F3F6` | 卡片缝取样即此色 | **与锁一致** |
| 遮罩 | 45% 黑 | 背后中灰，约 `#8C8C8C` | **与锁一致** |

只读旁证（解释观感，不是改锁的理由）：`apps/web-antd/src/preferences.ts` 中 `colorPrimary: 'hsl(215, 100%, 54%)'`，注释写「与 antd 默认颜色保持一致」；`colorSuccess / colorWarning / colorDestructive` 同组也偏向 Ant 默认，而不是梯控 HSL。`theme.mode` 为 `light`，`semiDarkSidebar: false`。

## 3. 表格列表页骨架

1. 查询区：`labelWidth: 80`；响应式 1～4 列。右端 **重置**、**搜索（主色）**、**收起**。
2. 工具栏：在表标题右侧。**新增**、导出、刷新、批量删除（未选中时常不可用）。树表另有收起 / 展开。新增打开的容器按 §4.1，不默认「一律抽屉」。
3. 表格：勾选 + 行操作（编辑为蓝色文字链，删除为红色文字链，可有「更多 / 新增子级」）。
4. 分页：左「共 n 条记录」+ 每页条数（实拍常见 10 条/页）；右页码，当前页主色实心。空态「暂无数据」。
5. 状态：实拍里「正常 / 启用」多用**主色浅底标签或主色开关**。成功绿 Tag 仍保留给成功 Message，不拿来画「正常」。

视觉：白卡片 + 主按钮（锁色蓝 `#006BE6`；现网观感见 §1.3）+ 危险红系文字链。

主从变体见 §4.5。字典必须按双表画，不能画成单表弹窗页。

## 4. 增改 · 右抽屉与居中 Modal

### 4.1 选用规则（t71u，按实拍）

| 优先用 | 条件 | 实拍代表 |
| --- | --- | --- |
| **右抽屉** | 字段多、有岗位/角色/菜单树、组织与账号增改、需对照左侧列表 | 用户、角色、菜单、部门、岗位、客户端、租户、租户套餐、OSS 配置、SpEL、请假 |
| **居中 Modal** | 短表单（约数个字段、无树） | 字典**类型**、参数设置、流程分类 |
| **居中 Modal** | 从已有数据里挑选，或上传 | 代码生成导入表、文件上传 |
| **宽居中 Modal** | 富文本或大块编辑，但不是「侧栏对照着改」 | 通知公告（只读 `w-[800px]`） |
| **约 400px Modal** | 梯控审批确认。**本批 52 条没有拍到** | 保留为审批专用，待林裁定是否仍专用 |

禁止：把流程定义新增画成右抽屉。实拍是居中 Modal（只读钩子为 `useVbenModal`，宽度类 `w-[550px]`）。

上传框可以没有页脚（文件上传实拍只有拖拽区与关闭）。关窗行为以页面为准，不套「取消 + 确认」。

### 4.2 宽度档

| 档 | 用于 | 说明 |
| --- | --- | --- |
| **600** | 平台右抽屉主档 | 用户、菜单、部门、岗位、客户端、租户、请假、SpEL、字典数据（数据抽屉本批未单独成片） |
| **650** | 字段分组较多的配置抽屉 | OSS 配置编辑 |
| **800** | 带整宽菜单树的抽屉；宽 Modal | 抽屉：角色、租户套餐。Modal：通知公告、导入表 |
| **550** | 梯控业务抽屉窄档；平台短 Modal 的显式宽 | 电梯域记忆保留。平台实拍：参数 Modal、流程定义 Modal。**不要**把平台主抽屉画成 550 |
| **约 520** | 未写宽度类的 Modal 默认（`w-130`） | 字典类型、流程分类、文件上传 |
| **约 400** | 审批 Modal | 仅梯控遗产；本批无实拍 |

园区业务新页（site / infra）在林未改档之前：**增改仍以右抽屉 550 / 650 / 800 为业务目标**；上表 600 是平台壳实拍，不自动替换电梯域 550。

### 4.3 抽屉结构

| 项 | 约定 |
| --- | --- |
| 组件 | 右开 Drawer。短表单 / 挑选 / 上传用 Modal，规则见 §4.1 |
| 宽度档 | 见 §4.2 |
| Footer | 取消（ghost）+ 确认（主色）。请假多一枚「暂存」 |
| 表单 | 平台实拍**单列、标签在上**居多。角色与租户套餐为顶部两列 + 下方树。园区业务页仍可两列，`showDefaultActions: false`（按钮走 footer） |
| 关闭 | 常禁点遮罩关闭；取消重置表单 |
| 上下文 | 效果图须露出左侧列表 + 遮罩，勿只裁抽屉 |

```
┌─────────────────────────────────────┐
│ 标题：新增 / 编辑              [×]   │
├─────────────────────────────────────┤
│ 表单（平台多为单列）                  │
│  标签                                │
│  控件                                │
├─────────────────────────────────────┤
│                    [取消]  [确认]     │
└─────────────────────────────────────┘
```

### 4.4 居中 Modal 结构

```
        ┌───────────────────────────┐
        │ 标题：新增            [×]  │
        ├───────────────────────────┤
        │ 短表单 / 表格挑选 / 拖拽区  │
        ├───────────────────────────┤
        │           [取消]  [确认]   │  ← 上传类可无此栏
        └───────────────────────────┘
        背后：列表 + 45% 遮罩
```

垂直表单、`showDefaultActions: false`、页脚取消 + 确认，与抽屉相同。字典类型实拍字段：字典名称、字典类型、备注。

### 4.5 主从（master-detail）

| 模式 | 页面 | 画法 |
| --- | --- | --- |
| 双表 | **字典** `/system/dict` | 左字典类型、右字典数据。两套查询、工具栏、分页。选中类型驱动右侧。类型增改用居中 Modal；数据增改用右抽屉（600，本批未单独成片，按只读组件，正式效果图需补一帧） |
| 树 + 表 | 用户 `/system/user`；流程定义 | 左树（部门或流程分类），右表。用户增改右抽屉；流程定义新增居中 Modal |
| 单表树 | 部门、菜单 | 一张可展开的表，工具栏有收起/展开。增改为右抽屉 |

假数据用园区语义时，主从关系照此骨架，文案不要用电梯设备。
